# Task 1 — BMI Calculator

## Overview
This is a beginner-friendly Python project that calculates Body Mass Index (BMI) using a person's weight and height.

## Technology Used
- Python 3

## Features
- Accepts weight in kilograms.
- Accepts height in meters.
- Calculates BMI using a mathematical formula.
- Displays the calculated BMI.

## Formula
BMI = Weight (kg) / Height (m)²

## How to Run
1. Install Python 3.
2. Download `bmi_calculator.py`.
3. Open a terminal in the project folder.
4. Run `python bmi_calculator.py`.
